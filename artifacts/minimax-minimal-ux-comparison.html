Normal chat

idle, no tools running

The current view mixes the sidebar, an active-session pill, two timestamps, and a four-button toolbar in the composer. The minimal view keeps one primary send button, drops the redundant timestamp on the bubble, and reserves the rail for context that earns space.

Active tool work

tool running

Today the running tool dumps raw output above an unsorted log and a spinner. The minimal view shows what the tool is, what it touched, and a single progress bar — output is collapsed by default and expanded on request.

Approval

write or side-effect pending

Approvals today bundle a long diff and four buttons in the same color, so users hesitate or guess. The minimal card names the action, scopes it, and shows one primary Approve next to a plain Decline. A keyboard shortcut is the same color as the action.

Error

tool failed

Today's error pane repeats the same stack three times and buries the fix under logs. The minimal view keeps the message human, hides the stack behind a single Show details, and offers one action: retry.

Interrupted / resume

session paused

When a session is interrupted, the current view asks two questions at once and offers four choices. The minimal view states where we stopped, what is queued, and offers one primary action: Resume.
